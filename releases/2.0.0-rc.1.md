# PlexonKeys 2.0.0-rc.1 — Phase 2 Premium Key Provenance Candidate

PlexonKeys 2.0.0-rc.1 is the Phase 2 release candidate built from the published `v1.4.1` rollback baseline.

## Product and API

- Preserves stable authoritative key IDs: `basic`, `rare`, `epic`, `legendary`.
- Preserves the complete 1.x Bukkit service method surface used by PlexonCrates.
- Adds immutable key-definition views and stable ID resolution.
- Adds exact physical-key identification through full Paper item metadata/components equality; display name/lore/material alone are never authoritative.
- Adds bounded transaction-ID guarded virtual-key consumption for exact-once integration debits.
- Adds synchronous post-commit `PlexonKeyConsumedEvent`.
- Preserves exact captured/configured physical templates so the frozen PlexonCrates 5.0 RC discovery contract remains compatible.

## Acquisition provenance

- Preserves the existing Core/local artificial-block provenance architecture and its `UNKNOWN != NATURAL` behavior.
- Adds conservative mob origin classification for natural, PlexonSpawners, external-spawner and unknown origins.
- Consumes PlexonSpawners 3.x provenance through an optional reflective Bukkit service bridge; there is no hard dependency or event-time database lookup.
- Spawner/unknown mob origins remain rejected unless explicitly opted in.
- Adds `/keysadmin dryrun <online-player> <key> <activity> <origin>` for read-only eligibility diagnosis without RNG, cooldown mutation, grant, event, persistence dirty, or item delivery.

## Admin / diagnostics / PlaceholderAPI

- Adds `/keysadmin definitions`.
- Extends diagnostics with definition IDs/count, schema state, physical identity mode, consume replay-guard pressure, and Crates/Spawners/PAPI integration state.
- Adds optional PlaceholderAPI expansion backed only by in-memory balances/config; no placeholder performs synchronous SQLite I/O.

## Persistence and compatibility

- Keeps configuration schema 1.
- Keeps SQLite schema 1.
- Keeps the single bounded SQLite worker and revision-coalesced dirty snapshots.
- Keeps current balances, artificial-block provenance and exact physical templates directly compatible with 1.4.1.
- No per-event, per-player or per-key task is added.
- No second provenance database/authority is added.

## Candidate certification boundary

**PLEXONCRAFT RUNTIME CERTIFICATION NOT EXECUTED.**

This is a GitHub prerelease candidate only. Stable `2.0.0` remains blocked until the runtime matrix passes, including:

- representative 1.4.1 migration;
- player load/reconnect and restart persistence;
- virtual balance grant/take/set/consume;
- exact physical-key identity and full-inventory claim behavior;
- NATURAL / PLAYER_PLACED / UNKNOWN provenance;
- PlexonSpawners first-party origin behavior;
- Core/local ownership with no double-credit;
- PlexonCrates consume/duplicate transaction behavior;
- admin dry-run/diagnostics;
- PlaceholderAPI and public API/events;
- reload rollback;
- Spark/MSPT comparison;
- minimum 30-minute soak;
- zero HIGH/CRITICAL defects.
