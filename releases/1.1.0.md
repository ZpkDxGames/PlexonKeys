PlexonKeys is created and maintained by **[Tonim (ZpkDxGames)](https://github.com/ZpkDxGames)**, as part of the **Plexon** plugin family.

### GUI chance editor

Includes all 1.0.0 features, plus:

- `/keysadmin chances` and a **Chance editor** shortcut in the main admin GUI.
- An overview of all 16 category/activity percentages.
- Percentage buttons for **±10**, **±1**, **±0.1**, **±0.01**, and **±0.001** percentage points.
- **Apply**, **Cancel**, **Reset draft**, **Never (0%)**, and **Always (100%)** controls.
- Optional exact input through private chat; it returns to the draft and still requires Apply.
- No disk writes while adjusting a draft and no added repeating server task.
- Configurable MiniMessage titles, button names, lore, and messages.
- Permission rechecks, invalidation of stale edits, and automatic loading of new defaults into existing configurations.

### Requirements and upgrade

Requires **Paper 26.2** and **Java 25**. Vault and an economy provider are needed only for cash bonuses.

1. Download **PlexonKeys-1.1.0.jar** from the release assets below.
2. Stop the server and remove the old PlexonKeys JAR.
3. Keep `plugins/PlexonKeys/config.yml` and `plexonkeys.db`; place the new JAR in `plugins/` and restart.
4. Open `/keysadmin chances` to configure the percentages. Click **Apply** to save a change.

Existing item bindings, virtual keys, and custom configuration values are preserved. New GUI defaults load automatically. Install only one PlexonKeys JAR. Shutdown-only saving cannot protect unsaved progress against a forced crash.

The release build runs **69 automated tests** before publishing, including 19 editor tests. `SHA256SUMS.txt` contains the JAR checksum. Check your specific crate, protection, and economy integrations on a staging server before production use.
