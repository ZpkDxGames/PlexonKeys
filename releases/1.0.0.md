PlexonKeys is created and maintained by **[Tonim (ZpkDxGames)](https://github.com/ZpkDxGames)**, as part of the **Plexon** plugin family.

### Initial release

- Basic, Rare, Epic, and Legendary virtual keys earned through natural mining, woodcutting, fishing, and mob kills.
- Independent drop percentages for every category/activity, eligibility filters, and placed-block tracking.
- `/keys` collection GUI with individual category claims, right-click to claim one key, and claim-all.
- Full held-item capture for physical keys, preserving metadata, NBT, and supported item data components.
- Admin category menus, a configuration browser, and precise chance entry through private chat or commands.
- MiniMessage styling, category announcements, optional Vault money bonuses, and XP bonuses.
- SQLite storage with shutdown saving, manual checkpoints, and optional periodic checkpoints disabled by default.

### Requirements and installation

Requires **Paper 26.2** and **Java 25**. Vault and an economy provider are needed only for cash bonuses.

1. Download **PlexonKeys-1.0.0.jar** from the release assets below.
2. Stop the server, place the JAR in `plugins/`, and restart.
3. Run `/keysadmin` to configure the plugin. Bind your real crate keys with `/keysadmin setitem <category>` while holding each key.

The bundled key templates are examples; they are not pre-bound to a crate plugin. Install only one PlexonKeys JAR. Shutdown-only saving cannot protect unsaved progress against a forced crash.

The release build runs **50 automated tests** before publishing. `SHA256SUMS.txt` contains the JAR checksum. Check your specific crate, protection, and economy integrations on a staging server before production use.
