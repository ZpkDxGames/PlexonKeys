# PlexonKeys 1.4.0

PlexonKeys 1.4.0 migrates high-frequency mining and logging acquisition to the PlexonCore 2 Runtime while keeping PlexonKeys authoritative for eligibility, reward rolls, balances, claims, persistence, GUI, commands, and public API/events.

## Runtime migration

- Uses the PlexonCore 2 block-break gateway when `core.runtime.mode` resolves to `CORE`.
- Keeps one local `BlockBreakEvent` compatibility path for forced `LOCAL` mode or unavailable Core Runtime.
- Routes both Core and local acquisition through the same `BlockActivityProcessor` reward policy.
- Uses final block-event cancellation and final `dropItems` semantics from PlexonCore 2.0.2.
- Fails closed when block origin is `UNKNOWN`.
- Retains PlexonKeys' conservative legacy/derived provenance overlay for exploit protection.

## Compatibility

- Existing keys, balances, captured physical key items, SQLite data, commands, GUI, public API, and public key events remain PlexonKeys-owned.
- Mob and fishing activity listeners remain local.
- PlexonCore classes are provided-only and are not shaded into the PlexonKeys JAR.

## Diagnostics

- Runtime mode and Core runtime detail are reported through diagnostics.
- Core-backed and local block acquisition remain mutually exclusive.
